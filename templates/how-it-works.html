How the Expert System Works

An end-to-end breakdown of how traditional Ayurvedic characteristics are translated into input facts, processed through a production rule base, and synthesized into an explainable classification.

The 8-Stage Inference Lifecycle

1

Step 1 — User Input

The user completes the 8-question assessment covering somatic, metabolic, physiological, and behavioral dimensions.

2

Step 2 — Fact Assertion

Each user selection is formalized as an asserted input fact in the expert system’s working memory (e.g., FACT: Frame = "Light and thin").

3

Step 3 — Knowledge Base Access

The system accesses the predefined knowledge base (rules.py), which contains codifications of classical Charaka and Sushruta Samhita principles.

4

Step 4 — Rule Evaluation

The inference engine pattern-matches the asserted fact against the premise of candidate IF-THEN rules (forward-chaining evaluation).

5

Step 5 — Score Assignment

When a rule’s condition evaluates to true, the rule fires and executes its consequent action: incrementing the targeted Dosha score by +1.

6

Step 6 — Final Inference

After processing all 8 queries, the inference engine compares the aggregated working memory totals for Vata, Pitta, and Kapha.

7

Step 7 — Classification

The highest-scoring Dosha is declared as the dominant constitutional classification (resolved via deterministic priority in the event of equal scores).

8

Step 8 — Explainable Reasoning Trace

Unlike opaque statistical neural networks, the system displays the full audit trail: which specific rules fired, why they fired, and how each answer impacted the score.
